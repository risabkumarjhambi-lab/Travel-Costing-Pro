How to use it — step by step guide

🚀 How to create a costing

1. On the Dashboard, enter the client name, pax, date, and currency.
2. From the Transfers tab, select a transfer and add it to the package.
3. Add entry tickets from the Tickets tab.
4. Add any extra service from the Services tab.
5. Go to the PDF tab to preview the full quotation and download/print it.
6. Click Saved Costing to save this costing for future use.

🔑 Admin vs User

A regular user can only create costings and generate PDFs. Admin Login is required to edit or save the master Transfer/Ticket/Service list (via the "Login as Admin" link on the login page).
